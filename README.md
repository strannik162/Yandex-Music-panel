# Yandex Music Panel

A Windows liquid-glass overlay panel for Yandex Music with track cover, title, artist, and playback controls.

## Features

- Liquid-glass style overlay panel for Windows
- **Move / Drag Panel**: Click and drag the panel anywhere on the screen
- **Pin Panel**: Pin button (★) keeps the panel visible on top without auto-hiding
- **Display Modes (Large & Small)**: Double-click the panel background to toggle between Large mode (with cover art, visualizer, seek bar) and Small mode (compact layout)
- **Audio Spectrum Visualizer**: Displays frequency visualization animated based on playback state
- **Interactive Track Seek Bar**: View current position/duration and click/drag to seek within the track
- Shows track title, artist, and album cover
- Play / pause, previous, and next track controls
- Integrated with Yandex Music via Windows System Media Transport Controls (SMTC)
- Can be launched as `.pyw` without a console window

## Requirements

- Windows 10 / Windows 11
- Python 3.10+
- Yandex Music desktop app
