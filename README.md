# Yandex Music Panel

A Windows liquid-glass overlay panel for Yandex Music with track cover, title, artist, and playback controls.

## Features

- Liquid-glass style overlay
- Shows track title, artist, and album cover
- Moveable panel: Drag the card to reposition anywhere on screen
- Spectrum visualizer: Graphic display of active audio frequencies and loudness
- Seek slider: Interactive track progress bar with seeking support
- Pin panel: Pin the panel in place to keep it visible
- Small / Large display modes: Double-click to toggle between compact view and detailed view
- Play / Pause, Previous, Next controls
- Works with Yandex Music through Windows media controls
- Can be launched as `.pyw` without a console window

## Requirements

- Windows 10 / Windows 11
- Python 3.10+
- Yandex Music desktop app
