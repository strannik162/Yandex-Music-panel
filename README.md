# Yandex Music Panel

A Windows liquid-glass overlay panel for Yandex Music with track cover, title, artist, and playback controls.

## Features

- **Liquid-glass style overlay**: Modern translucent desktop overlay design.
- **Draggable & Movable**: Drag the panel anywhere on your screen.
- **Spectrum Audio Visualizer**: Graphical visualizer displaying active sound frequencies (bass, mid, treble) and volume intensity in real time.
- **Interactive Seek Bar**: Track position progress bar with scrub seeking capabilities.
- **Compact & Large Modes**: Double-click the panel card background to switch between Large (full details, cover, visualizer & seek bar) and Small (compact control) modes.
- **Pin Panel**: Toggle the pin button (★) to keep the panel pinned on top of screen.
- **Media Information**: Displays track cover art, title, artist, and playback status.
- **Playback Controls**: Play/pause, next track, and previous track buttons integrated with Yandex Music via Windows Media Controls.
- **No Console Window**: Can be launched as `.pyw` without displaying a command prompt window.

## Requirements

- Windows 10 / Windows 11
- Python 3.10+
- Yandex Music desktop app
