# Yandex Music Panel

A Windows liquid-glass overlay panel for Yandex Music with track cover, title, artist, and playback controls.

## Features

- Liquid-glass style overlay panel
- Drag and move panel anywhere on screen (manual positioning)
- Real-time spectrum frequency visualizer showing active sound frequencies and volume levels
- Pin button (★) to keep the panel pinned on top without auto-hiding
- Large and Small mode toggle: double-click the panel background to switch modes (Small mode hides cover, visualizer, and seek bar)
- Interactive track seek bar with elapsed and total time display for rewinding / seeking
- Shows track title, artist, album, and cover art
- Play / pause, previous, and next track buttons with tooltips
- Works with Yandex Music through Windows System Media Transport Controls (SMTC)
- Can be launched as `.pyw` without a console window

## Requirements

- Windows 10 / Windows 11
- Python 3.10+
- Yandex Music desktop app
