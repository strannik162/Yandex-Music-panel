# Yandex Music Panel

A Windows liquid-glass overlay panel for Yandex Music with track cover, title, artist, and playback controls.

## Features

- **Liquid-glass style overlay**: Translucent, modern UI desktop widget.
- **Track Metadata & Cover Art**: Displays track title, artist name, and album cover art.
- **Playback Controls**: Play / pause, previous track, and next track buttons.
- **Interactive Track Seek Slider**: Interactive progress bar with time indicators and seek capability.
- **Real-time Spectrum Audio Visualizer**: Animated spectrum bars displaying dynamic frequency amplitudes when audio is playing.
- **Movable Overlay**: Drag and drop the panel anywhere on your screen.
- **Pin / Unpin Panel**: Pin the panel to keep it permanently visible or unpin for top-edge hover auto-reveal/hide.
- **Large & Small Display Modes**: Double-click the panel background to toggle between Large mode (full detailed UI) and Small mode (compact bar).
- **Windows Media Controls (SMTC) Integration**: Seamlessly syncs with the official Yandex Music desktop app.
- **Silent Launch**: Can be launched directly as `.pyw` without showing a console window.

## Requirements

- Windows 10 / Windows 11
- Python 3.10+
- Yandex Music desktop app
