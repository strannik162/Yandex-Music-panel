# Yandex Music Panel

A Windows liquid-glass overlay panel for Yandex Music with track cover, title, artist, and playback controls.

## Features

- Liquid-glass style overlay
- Shows track title, artist, and album cover
- Spectrum audio visualizer showing frequency dynamics
- Track position seek bar with real-time progress and duration display
- Draggable positioning (click and drag anywhere on the panel background)
- Pin button (★) to keep the panel visible on screen
- Small & Large display modes (double-click the panel background to toggle):
  - **Large mode**: displays album cover, track info, controls, visualizer, and seek slider
  - **Small mode**: compact view with track info and playback controls
- Works with Yandex Music through Windows media controls (SMTC)
- Can be launched as `.pyw` without a console window

## Requirements

- Windows 10 / Windows 11
- Python 3.10+
- Yandex Music desktop app
