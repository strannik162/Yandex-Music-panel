# Yandex Music Panel

A Windows liquid-glass overlay panel for Yandex Music with track cover, title, artist, and playback controls.

## Features

- **Liquid-glass style overlay**: Sleek translucent desktop widget for Windows
- **Interactive track controls & seeking**: Play, pause, skip tracks, and interactively seek through the current track
- **Spectrum frequency visualizer**: Animated sound wave visualizer displaying active frequencies during music playback
- **Draggable & repositionable panel**: Drag and move the panel anywhere on your screen
- **Panel pinning**: Lock the panel on screen to stay visible regardless of mouse hover
- **Large & Small mode toggle**: Double-click the panel background to switch between Large view (with cover art, visualizer, and seek slider) and Small compact view
- **Track metadata & album cover**: Displays track title, artist name, and high-resolution cover art via Windows System Media Transport Controls (SMTC)
- Can be launched as `.pyw` without a console window

## Requirements

- Windows 10 / Windows 11
- Python 3.10+
- Yandex Music desktop app
