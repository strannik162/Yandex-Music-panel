# Yandex Music Panel

A Windows liquid-glass overlay panel for Yandex Music with track cover, title, artist, and playback controls.

## Features

- **Liquid-Glass Style Overlay**: Elegant semi-transparent desktop panel for Yandex Music.
- **Draggable & Movable Panel**: Click and drag the panel background to place it anywhere on screen.
- **Spectrum Frequency Visualizer**: Displays real-time audio frequencies (bass, mid, treble) and volume intensity.
- **Track Seek Bar**: Shows track progress and duration, allowing interactive seeking via click or handle drag.
- **Pin Panel**: Keep the panel pinned on screen or let it hide automatically when unhovered.
- **Large & Small Modes**: Double-click the panel background to toggle between Large mode (with cover, visualizer, and seek bar) and Compact Small mode.
- **Track Metadata**: Displays album artwork cover, track title, artist name, and target application.
- **Playback Controls**: Previous, Play / Pause, Next, Pin, and Close buttons with tooltips.
- **Windows SMTC Integration**: Interoperates directly with the desktop Yandex Music app.
- **Background Launch**: Runs cleanly via `yandex-liquid-panel.pyw` without opening a console window.

## Requirements

- Windows 10 / Windows 11
- Python 3.10+
- Yandex Music desktop app
