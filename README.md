# Yandex Music Panel

A Windows liquid-glass overlay panel for Yandex Music with track cover, title, artist, and playback controls.

## Features

- **Liquid-glass style overlay**: Modern semi-transparent glass UI with smooth animations and shadows.
- **Draggable panel**: Move the panel anywhere on screen by dragging.
- **Pin mode (★)**: Pin the panel so it stays visible on top of other windows.
- **Spectrum visualizer**: Dynamic audio frequency bar animation showing playing frequencies and volume levels.
- **Interactive seek bar**: Display current playback time and total track duration with click & drag seeking.
- **Large & Small display modes**: Double-click the panel background to toggle between expanded (Large) mode and compact (Small) mode.
- **Track information**: Shows cover art, title, artist, and media source app info.
- **Playback controls**: Play/pause, next track, and previous track buttons.
- **Windows Media Integration**: Works seamlessly with Yandex Music through Windows media controls (SMTC).
- **Background launch**: Can be launched as `.pyw` without a console window.

## Requirements

- Windows 10 / Windows 11
- Python 3.10+
- Yandex Music desktop app
