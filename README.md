# Yandex Music Panel

A Windows liquid-glass overlay panel for Yandex Music with track cover, title, artist, and playback controls.

## Features

- Liquid-glass style overlay
- Shows track title and artist
- Shows track cover
- Interactive spectrum audio visualizer displaying real-time frequencies
- Track playback position seek slider with interactive scrubbing
- Large and Small panel modes (toggle by double-clicking the panel card)
- Panel position dragging / free repositioning on desktop
- Pin button to keep panel visible on screen
- Play / pause, previous, and next track controls
- Works with Yandex Music through Windows media controls
- Can be launched as `.pyw` without a console window

## Requirements

- Windows 10 / Windows 11
- Python 3.10+
- Yandex Music desktop app
