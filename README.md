# Yandex Music Panel

A Windows liquid-glass overlay panel for Yandex Music with track cover, title, artist, and playback controls.

## Features

- Liquid-glass style overlay
- Shows track title, artist, and album cover
- Play / pause, previous, and next track buttons
- **Movable panel**: Drag the panel with mouse to position it anywhere on the screen
- **Pin capability**: Pin the panel in place with the star button so it stays visible
- **Large & Small modes**: Double-click the panel background to toggle between Large mode (with cover, visualizer, and seek slider) and Small mode (compact layout)
- **Audio spectrum visualizer**: Frequency bars displaying real-time music activity and volume dynamics
- **Track seek bar**: Interactive progress bar with elapsed/total time and drag-to-seek functionality
- Works with Yandex Music via Windows System Media Transport Controls (SMTC)
- Can be launched as `.pyw` without a console window

## Requirements

- Windows 10 / Windows 11
- Python 3.10+
- Yandex Music desktop app
