# Yandex Music Panel

A Windows liquid-glass overlay panel for Yandex Music with track cover, title, artist, and playback controls.

## Features

- **Liquid-glass style overlay**: Elegant semi-transparent floating desktop widget.
- **Track metadata & Cover**: Shows track title, artist, and album artwork.
- **Playback controls**: Previous track, play / pause, and next track.
- **Dragging / Manual positioning**: Click and drag the panel card to position it anywhere on screen.
- **Audio spectrum visualizer**: Dynamic real-time graphic frequency bars showing frequency levels and music loudness.
- **Track seeking bar**: Interactive progress bar with elapsed and remaining time, supporting click-and-drag seeking.
- **Panel pinning**: Pin button (★) locks the panel open on screen to prevent auto-hiding.
- **Large & Small display modes**: Double-click the panel background to toggle between Large mode (with cover art, visualizer, and seek bar) and Small mode (compact layout).
- **Windows Media Controls**: Integrates directly with Yandex Music desktop app via Windows SMTC.
- **No console window**: Can be launched directly as `.pyw`.

## Requirements

- Windows 10 / Windows 11
- Python 3.10+
- Yandex Music desktop app
