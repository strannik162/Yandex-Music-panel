# Yandex Music Panel

A Windows liquid-glass overlay panel for Yandex Music with track cover, title, artist, and playback controls.

## Features

- Liquid-glass style overlay window with smooth animations
- Drag to reposition panel anywhere on screen
- Audio spectrum visualizer showing music frequency dynamics
- Seek bar with time progress and interactive track scrubbing/seeking
- Double-click card to toggle between Large (full view) and Small (compact) modes
- Pin button to keep panel visible on screen
- Play / pause, previous, and next track buttons
- Works with Yandex Music through Windows media controls (SMTC)
- Can be launched as `.pyw` without a console window

## Requirements

- Windows 10 / Windows 11
- Python 3.10+
- Yandex Music desktop app
