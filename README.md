# Yandex Music Panel

A Windows liquid-glass overlay panel for Yandex Music with track cover, title, artist, and playback controls.

## Features

- Liquid-glass style overlay
- Shows track title and artist
- Shows track cover art
- Play / pause button
- Previous and next track buttons
- **Manual Window Dragging**: Click and drag anywhere on the panel background to reposition it on screen.
- **Spectrum Visualizer**: Real-time graphic display of audio frequencies and amplitude dynamics.
- **Interactive Track Seek Bar**: Click or drag on the seek slider to jump to any track position with animated time indicators.
- **Small / Large Display Modes**: Double-click the panel background to toggle between Large (full visualizer, slider, cover art) and Small (compact control bar) modes.
- **Pin Panel**: Toggle the pin button (★) to keep the panel permanently visible without hover auto-hiding.
- Works with Yandex Music through Windows media controls (SMTC)
- Can be launched as `.pyw` without a console window

## Requirements

- Windows 10 / Windows 11
- Python 3.10+
- Yandex Music desktop app
