# Yandex Music Panel

A Windows liquid-glass overlay panel for Yandex Music with track cover, title, artist, and playback controls.

## Features

- Liquid-glass style overlay
- Shows track title and artist
- Shows track cover (in Large mode)
- Audio spectrum visualizer displaying active sound frequencies
- Track progress bar / seek slider with interactive seeking
- Double-click toggle between Large (full features) and Small (compact control bar) modes
- Draggable panel positioning to move the panel anywhere on screen
- Pin button to keep the panel permanently visible on top
- Play / pause, previous, and next track buttons
- Works with Yandex Music through Windows media controls
- Can be launched as `.pyw` without a console window

## Requirements

- Windows 10 / Windows 11
- Python 3.10+
- Yandex Music desktop app
