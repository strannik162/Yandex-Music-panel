# Yandex Music Panel

A Windows liquid-glass overlay panel for Yandex Music with track cover, title, artist, and playback controls.

## Features

- Liquid-glass style overlay
- Shows track title, artist, and album cover
- Interactive spectrum audio visualizer (frequencies and loudness)
- Track seek bar with drag-to-seek and time display
- Small and Large panel modes (double-click card background to toggle)
- Panel pinning feature (pin icon button) to keep overlay on screen
- Draggable panel overlay for custom screen positioning
- Play / pause, previous, and next track playback controls
- Works with Yandex Music through Windows media controls (SMTC)
- Can be launched as `.pyw` without a console window

## Requirements

- Windows 10 / Windows 11
- Python 3.10+
- Yandex Music desktop app
