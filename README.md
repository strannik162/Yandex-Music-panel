# Yandex Music Panel

A Windows liquid-glass overlay panel for Yandex Music with track cover, title, artist, and playback controls.

## Features

- **Liquid-glass style overlay**: Sleek translucent aesthetic with smooth animations.
- **Movable / Draggable Panel**: Drag the panel freely around your screen to any desired position.
- **Spectrum Visualizer**: Animated multi-bar visualizer showing active sound frequencies and playback intensity.
- **Track Seeking**: Interactive progress bar with time indicators allowing direct position seeking.
- **Small & Large Display Modes**: Double-click the panel background to switch between Large mode (with cover art, visualizer, seek slider) and Small compact mode.
- **Pin Overlay**: Toggle pinning (★ button) to keep the panel permanently visible on top.
- **Playback Controls**: Play, pause, previous track, and next track buttons integrated with Windows media controls.
- **Media Info**: Displays current track title, artist, app name, and album cover art.
- **Silent Launch**: Can be launched directly as `.pyw` without showing a console window.

## Requirements

- Windows 10 / Windows 11
- Python 3.10+
- Yandex Music desktop app
