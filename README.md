# Yandex Music Panel

A Windows liquid-glass overlay panel for Yandex Music with track cover, title, artist, and playback controls.

## Features

- Liquid-glass style overlay
- Shows track title, artist, and album cover
- Audio frequency spectrum visualizer with distinct bass, mid, and treble frequency bands
- Interactive seek bar with current position, duration, and drag/click seeking
- Moveable overlay: drag the panel to position it anywhere on the screen
- Pin/unpin feature: pin the panel to keep it always visible on screen
- Large and Small mode toggle: double-click the panel background to toggle between full view and a compact mini-player
- Play / pause, previous, and next track playback controls
- Bilingual tooltips for controls and indicators
- Works with Yandex Music through Windows media controls
- Can be launched as `.pyw` without a console window

## Requirements

- Windows 10 / Windows 11
- Python 3.10+
- Yandex Music desktop app
