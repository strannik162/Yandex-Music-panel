# Yandex Music Panel

A Windows liquid-glass overlay panel for Yandex Music with track cover, title, artist, and playback controls.

## Features

- **Liquid-glass Overlay Style**: Aesthetic translucent design matching desktop UI.
- **Track Info & Cover Art**: Displays current track title, artist, app name, and high-resolution cover art.
- **Playback Controls**: Play/Pause, Next Track, Previous Track.
- **Spectrum Visualizer**: Real-time frequency visualizer displaying playing audio frequencies and amplitude levels.
- **Track Seeking & Progress Slider**: Interactive seek bar displaying elapsed and total duration with drag & click seek support.
- **Movable Panel**: Click and drag anywhere on the panel background to move it freely across the desktop.
- **Pin Panel**: Keep the panel permanently visible on screen without auto-hiding.
- **Large & Small Display Modes**: Double-click the panel card to toggle between Compact (Small) mode and Expanded (Large) mode with cover art, visualizer, and seek slider.
- **Windows SMTC Integration**: Works seamlessly with Yandex Music desktop application via Windows System Media Transport Controls.
- Can be launched as `.pyw` without a console window.

## Requirements

- Windows 10 / Windows 11
- Python 3.10+
- Yandex Music desktop app
