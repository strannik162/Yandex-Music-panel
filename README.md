# Yandex Music Panel

A Windows liquid-glass overlay panel for Yandex Music with track cover, title, artist, and playback controls.

## Features

- Liquid-glass style overlay
- Shows track title and artist
- Shows track cover (in large mode)
- Play / pause button
- Previous and next track buttons
- **Draggable panel**: click and drag anywhere on the panel to reposition it on your screen
- **Pin panel**: pin the panel (★) to keep it always visible without auto-hiding
- **Frequency spectrum visualizer**: real-time frequency bar display with dynamic bands (bass in cyan, mids in emerald, treble in coral) and amplitude loudness feedback
- **Large and Small modes**: double-click the panel background to toggle between compact mini-player mode and full mode with cover, visualizer, and seek bar
- **Track seek bar**: interactive progress bar allowing smooth scrubbing and jumping to any position in the song
- Works with Yandex Music through Windows media controls
- Can be launched as `.pyw` without a console window

## Requirements

- Windows 10 / Windows 11
- Python 3.10+
- Yandex Music desktop app
