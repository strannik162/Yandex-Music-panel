# Yandex Music Panel

A Windows liquid-glass overlay panel for Yandex Music with track cover, title, artist, and playback controls.

## Features

- Liquid-glass style overlay
- Shows track title, artist, and application info
- Shows track cover art
- Interactive controls: Play/Pause, Previous, Next
- **Draggable / Movable panel**: Drag the panel anywhere on your screen
- **Spectrum Visualizer**: Procedural audio frequency visualization with bass, mid, and treble frequency band tinting
- **Track Seek Bar**: Interactive progress bar with time display and seeking capability
- **Panel Pinning**: Pin button (★) to keep the panel always visible on screen
- **Compact & Expanded Modes**: Double-click the panel background to switch between Large (with visualizer, seek slider, cover art) and Small (compact control overlay) modes
- Works with Yandex Music through Windows System Media Transport Controls (SMTC)
- Can be launched as `.pyw` without a console window

## Requirements

- Windows 10 / Windows 11
- Python 3.10+
- Yandex Music desktop app
