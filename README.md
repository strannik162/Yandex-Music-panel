# Yandex Music Panel

A Windows liquid-glass overlay panel for Yandex Music with track cover, title, artist, and playback controls.

## Features

- Liquid-glass style overlay widget
- Interactive track seek slider with current time and duration
- Dynamic audio frequency spectrum visualizer (bass, mids, treble response with dynamic intensity)
- Move/drag panel anywhere on screen
- Pin panel (★ button) to keep it visible continuously
- Toggle between Large (full controls, cover, visualizer, seek bar) and Small modes by double-clicking the panel card
- Play / pause, previous, and next track buttons
- Works with Yandex Music via Windows System Media Transport Controls (SMTC)
- Can be launched as `.pyw` without a console window

## Requirements

- Windows 10 / Windows 11
- Python 3.10+
- Yandex Music desktop app
