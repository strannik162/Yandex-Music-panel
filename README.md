# Yandex Music Panel

A Windows liquid-glass overlay panel for Yandex Music with track cover, title, artist, and playback controls.

## Features

- **Liquid-glass style overlay**: Translucent, sleek desktop overlay with smooth animations.
- **Draggable panel**: Move the panel anywhere on the screen by dragging.
- **Spectrum visualizer**: Live animated audio frequency spectrum showing bass, mid, and treble frequencies and loudness.
- **Interactive seek slider**: Scrub through tracks with real-time position display and click/drag seeking.
- **Display modes (Large / Small)**: Double-click the panel background to toggle between full view (with cover, visualizer, and seek slider) and compact view.
- **Pin panel**: Keep the panel permanently visible on screen.
- **Playback controls**: Play / pause, previous, and next track buttons with tooltips.
- Works seamlessly with Yandex Music via Windows System Media Transport Controls (SMTC).
- Can be launched as `.pyw` without a console window.

## Requirements

- Windows 10 / Windows 11
- Python 3.10+
- Yandex Music desktop app
