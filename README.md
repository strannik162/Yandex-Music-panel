# Yandex Music Panel

A Windows liquid-glass overlay panel for Yandex Music with track cover, title, artist, and playback controls.

## Features

- Liquid-glass style overlay
- Shows track title and artist
- Shows track cover
- Play / pause button, Previous and next track buttons
- Track seek bar with absolute seeking support
- Simulated procedural audio visualizer
- Draggable window with manual positioning
- Pinning feature to prevent auto-hide
- Toggleable Small and Large modes (Double-click to switch)
- Works with Yandex Music through Windows media controls
- Can be launched as `.pyw` without a console window

## Requirements

- Windows 10 / Windows 11
- Python 3.10+
- Yandex Music desktop app
