# Yandex Music Panel

A Windows liquid-glass overlay panel for Yandex Music with track cover, title, artist, playback controls, audio spectrum visualizer, seek slider, pinning, and mode toggling.

## Features

- **Liquid-glass style overlay**: Sleek translucent desktop widget for Windows.
- **Draggable Panel**: Click and drag anywhere on the card background to move the panel to a custom screen position.
- **Spectrum Visualizer**: Real-time graphic display of active sound frequencies and volume levels during playback.
- **Track Seek Slider**: Seek bar showing current position and duration with interactive clicking and dragging support.
- **Pin Panel**: Pin button (star icon) to keep the panel pinned on top without auto-hiding on mouse leave.
- **Large & Small Modes**: Double-click the panel background to toggle between Large mode (full view with cover art, visualizer, and seek bar) and Small mode (compact bar).
- **Playback Controls**: Play/pause, previous, next, and close buttons.
- **Works with Yandex Music**: Connects via Windows System Media Transport Controls (SMTC).

## Requirements

- Windows 10 / Windows 11
- Python 3.10+
- Yandex Music desktop app
