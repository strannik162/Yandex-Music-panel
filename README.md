# Yandex Music Panel

A Windows liquid-glass overlay panel for Yandex Music with track cover, title, artist, and playback controls.

## Features

- **Liquid-glass style overlay**: Translucent, glass-like aesthetic desktop panel.
- **Track Metadata**: Displays track title, artist name, and album cover art.
- **Playback Controls**: Play/pause, next track, previous track, and close buttons with tooltips.
- **Interactive Audio Visualizer**: Procedural spectrum bar visualizer showing animated frequency bands during playback.
- **Track Seek Bar**: Interactive progress bar supporting click and drag seeking with time indicators.
- **Free Dragging & Positioning**: Drag the panel anywhere on screen to reposition it manually.
- **Pin Panel Mode**: Pin button keeps the panel continuously visible on desktop without auto-hiding.
- **Large & Small Modes**: Double-click the panel background to toggle between Large (full view) and Small (compact control bar without visualizer/cover) modes.
- **Windows SMTC Integration**: Works seamlessly with the Yandex Music desktop app using native Windows media transport controls.
- **No Console Window**: Can be launched directly as a `.pyw` script.

## Requirements

- Windows 10 / Windows 11
- Python 3.10+
- Yandex Music desktop app
