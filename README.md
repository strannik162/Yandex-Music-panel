# Yandex Music Panel

A Windows liquid-glass overlay panel for Yandex Music with track cover, title, artist, and playback controls.

## Features

- Liquid-glass style overlay
- Shows track title, artist, and application source
- Shows track cover art
- Audio spectrum visualizer (real-time graphical audio frequency visualization)
- Interactive seek bar slider for track position and time rewinding/fast-forwarding
- Drag-to-move custom panel positioning across the desktop
- Pin button to pin the panel permanently visible on screen
- Double-click to toggle between Large mode (with cover, visualizer, seek slider) and Small mode (compact bar)
- Play / pause, previous track, and next track controls
- Works with Yandex Music through Windows media controls (SMTC)
- Can be launched as `.pyw` without a console window

## Requirements

- Windows 10 / Windows 11
- Python 3.10+
- Yandex Music desktop app
